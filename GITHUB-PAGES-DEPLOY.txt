GUSTAVO'S COINTAB V46 — GITHUB PAGES DEPLOYMENT

This is the static GitHub dashboard. It must be published from the repository root (or the selected Pages folder).
GitHub Pages does not execute PHP. Therefore:
- config.js must use https://api.rentaride.top/api/v1
- proxyUrl must remain empty on GitHub Pages
- the API server must allow the exact GitHub Pages origin in CORS
- never put API passwords, signing keys, database credentials, or private tokens in this repository

To publish:
1. Extract this package.
2. Open dashboard/UPLOAD-DASHBOARD-TO-GITHUB.cmd on a Windows PC with Git and GitHub CLI (gh) installed.
3. Review the script's repository name before running. It currently targets christianjoy00/gustavos-cointab-download.
4. Sign in using `gh auth login` when prompted.
5. Run the script, then enable GitHub Pages for the main branch/root if not already enabled.
6. Test login, dashboard data, licenses, commands, and tablet updates.

The cPanel dashboard is separate and should use its same-origin PHP proxy. Do not upload PHP proxy files as a substitute for the GitHub static frontend.

V46 feature note:
The dashboard UI includes the 50-game deployment action and Application Policies controls. These controls only work if the existing API and Android device command handlers implement the matching actions; test on one tablet before fleet-wide use.
