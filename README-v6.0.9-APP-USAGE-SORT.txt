Gustavo's Cointab Dashboard v6.0.9 — Simple App Usage Sort

Location -> UNINSTALL APPS now includes one SORT dropdown:
- NAME A-Z
- NAME Z-A
- SIZE: LARGEST
- SIZE: SMALLEST
- USAGE: MOST USED
- USAGE: LEAST USED

Each app card shows storage size and usage time. Location usage is the sum of that app's reported foreground usage across tablets in the location.
